# HoqaBot

Установка:

```bash
pip install -r requirements.txt
python bot.py
```

Токен берётся из `BOT_TOKEN`.

Папка `images/` содержит оформление и GIF-анимации футбола/баскетбола.

Перед запуском добавьте бота администратором в `@hoqanft`, иначе Telegram не позволит проверять подписку.

NFT-ссылка в `NFT_LINKS` — пример. Перед реальным запуском замените её на вашу действительную ссылку на коллекционный подарок.
